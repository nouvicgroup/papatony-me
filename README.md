# PapaTony.me

The official website of **Apostle Dr. Anthony Nkumbe**, known as **Papa Tony** — a Cameroon-based entrepreneur, certified real estate consultant, investment facilitator, institution builder and ministry founder.

This repository is the source of that one website. It is not a template.

The site is available in English and French.

---

## About Papa Tony

Anthony Nkumbe trained as an agronomist at FASA, University of Dschang. His work now spans property, enterprise, cooperatives and investment facilitation, alongside his ministry and leadership roles.

He works as a connector — helping founders, property owners, investors and institutions qualify an opportunity in Cameroon, meet the right local counterparts, and decide on a next step.

### Enterprise and property

- Chief Executive, Rainbow Group of Companies
- Certified real estate consultant, negotiator and facilitator
- Low-cost building facilitator for multiple municipalities
- Vice President, CHEDE Union of Cooperatives
- Executive member, Africa Arise Business Consortium
- Technical adviser to processing companies
- International investment negotiator

### Leadership and ministry

- Founder, Eagles' Family Assembly — [eaglesfamily.org](https://eaglesfamily.org)
- President, Eagles' School of Ministry, Entrepreneurship and Leadership (ESMEL)
- Convener, Eagles Leadership Empowerment Summit (ELES), Dominion Prayer Conference (DPC) and Ministers Business Summit (MBS)
- Regional coordinator for West Africa, Kingdom World for Jesus Int'l Church Fellowship
- President, Eagle Apostolic College
- President, Bakossi All Ministers Association (BAMA)
- Executive member, Christian Association of Gospel Ministers (CAGOM), Cameroon

### Education

- Agronomy — FASA, University of Dschang
- Full Gospel Bible Institute
- Cornerstone University and Seminary
- Evangel Theological Seminary

He is married to Rev. Carine Nkumbe. They have four biological children, and a wider family of adopted and spiritual sons and daughters.

## Built with

Next.js on Vite ([vinext](https://github.com/cloudflare/vinext)), React, TypeScript, plain CSS. Deployed as a Cloudflare Worker.

```bash
npm install
npm run dev     # local development
npm run build   # production build
npm run lint
npm test        # server-render tests
npm run test:e2e
```
